# Public brand asset convention

Upload only approved brand assets supplied by the internal team. Do not replace real project photos or official documents with generic stock imagery.

## Project folders

- `zia-properti/logos/`: approved corporate logo variants.
- `zia-emerald/logos/`: ZIA Emerald logo variants.
- `zia-emerald/images/hero/`: approved website hero photography.
- `zia-emerald/images/units/`: supplied Type 50/72 and Type 80/72 facade and detail photographs.
- `zia-emerald/images/interior/`: approved interior reference imagery.
- `zia-emerald/images/facilities/`: supplied wider area and sports-field visual.
- `zia-emerald/images/site-plan/site-plan-utama.webp`: official site-plan image used by the ZIA Emerald page when supplied.
- `zia-emerald/downloads/site-plan-resmi.pdf`: optional approved PDF masterplan for public download.
- `kav-hillside/logos/`, `images/site-plan/`, `maps/`, `downloads/`: approved project assets and public documents.
- `zia-farm/logos/`, `images/`, `videos/`, `downloads/`: approved livestock, facilities, and catalog assets.
- `altara-zia-international/logos/`, `images/`, `videos/`, `downloads/`: approved vanilla-origin, quality-control, packaging, and export assets.

Keep private buyer records, internal contracts, personal data, API keys, unpublished pricing sheets, and internal documents outside `public/`. Files under `public/` become publicly accessible after deployment.

## ZIA Emerald unit and interior image mapping

The ZIA Emerald website uses these exact public paths:

- `zia-emerald/images/hero/hero-utama-zia-emerald.webp` — hero banner.
- `zia-emerald/images/units/zia-emerald-fasad-type-50-72.webp` — Type 50/72 main facade.
- `zia-emerald/images/units/zia-emerald-fasad-type-50-72-angle.webp` — Type 50/72 alternate facade view.
- `zia-emerald/images/units/zia-emerald-fasad-type-80-72.webp` — Type 80/72 main facade.
- `zia-emerald/images/units/zia-emerald-fasad-type-80-72-detail.webp` — Type 80/72 detail view.
- `zia-emerald/images/interior/zia-emerald-interior-ruang-tamu.webp` — interior reference shown in the type galleries.
- `zia-emerald/images/facilities/zia-emerald-area-komunal.webp` — general area/facility reference.

Type 65/72 mezzanine is intentionally not assigned an exact type-specific photograph because the supplied set does not clearly identify one. The page labels the main project visual accordingly.
