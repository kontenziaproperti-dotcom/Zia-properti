# Public brand asset convention

Upload only approved brand assets supplied by the internal team. Do not replace real project photos or official documents with generic stock imagery.

## Project folders

- `zia-properti/logos/`: approved corporate logo variants.
- `zia-emerald/logos/`: ZIA Emerald logo variants.
- `zia-emerald/images/hero/`: approved website hero photography.
- `zia-emerald/images/site-plan/site-plan-utama.webp`: official site-plan image used by the ZIA Emerald page when supplied.
- `zia-emerald/downloads/site-plan-resmi.pdf`: optional approved PDF masterplan for public download.
- `kav-hillside/logos/`, `images/site-plan/`, `maps/`, `downloads/`: approved project assets and public documents.
- `zia-farm/logos/`, `images/`, `videos/`, `downloads/`: approved livestock, facilities, and catalog assets.
- `altara-zia-international/logos/`, `images/`, `videos/`, `downloads/`: approved vanilla-origin, quality-control, packaging, and export assets.

Keep private buyer records, internal contracts, personal data, API keys, unpublished pricing sheets, and internal documents outside `public/`. Files under `public/` become publicly accessible after deployment.
